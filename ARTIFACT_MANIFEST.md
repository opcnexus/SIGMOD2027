## 2. 刻意排除的内容（及原因）

| 被排除                                         |      体量 | 原因                                             |
| ------------------------------------------- | ------: | ---------------------------------------------- |
| 原始消息语料（IRC/Molweni/HN/Reddit/Discord/Slack） | ~1.3 GB | 授权不一致；Slack 为内部导出不可再分发（见 DATA_STATEMENT.md）    |
| Slack silver 标签（全量）                         |       — | 含用户名（个人数据）；仅提供 200 条假名化+正文移除的样例                |
| `results/frozen_cache/`                     |   17 GB | 特征缓存，可由 `src/transfer_experiment.py` 重建        |
| 模型权重 `*.pt`                                 |  ~20 MB | 可由探针训练脚本重建                                     |
| `ecb_v3_all.jsonl/.csv/.xlsx`               |  ~25 MB | 结论已由 `ecb_v3_constraint.jsonl` 与论文 §6.7 负结果段承载 |
| `pred_links*.json`                          | ~4.6 MB | 逐边预测转储；可用 `src/gen_pred_links*.py` 重建          |
| 论文 PDF（`papers/`）                           |  294 MB | 第三方版权，不随工件再分发                                  |
| LLM 调用日志的 `response` 字段                     |       — | 可能包含会话内容；仅保留元数据                                |
| 任何 API 密钥 / 本机路径 / 用户名                      |       — | 双盲合规；由 `scripts/verify_artifact.py` 自动扫描       |
